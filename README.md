# 你好，我是 Ethan Chen

我做遥感和地理信息系统（GIS）工具。给定一块地，我最想知道的是：最近哪天拍到了它？云有没有挡住？哪一景影像值得下载？这些问题也是我开发 Geomapper 的出发点。

## 我在做的项目 · Geomapper

Geomapper 是一个查找和获取卫星影像的地图工作台。比如，想看看一块农田在一个生长季里的变化，可以先在地图上画出地块，或导入已有的边界，再按日期和云量筛选 Sentinel-2、Landsat 影像。挑出感兴趣的几景，先在地图上预览，再提交下载。保存好地块，下次就能沿用同一片研究区。

[打开 Geomapper](https://geomapper.luyuancloud.com)

我也关注遥感影像超分辨率和地球观测基础模型。如果你也在用卫星数据，欢迎聊聊你研究的区域，以及你在找影像时遇到过什么麻烦。
